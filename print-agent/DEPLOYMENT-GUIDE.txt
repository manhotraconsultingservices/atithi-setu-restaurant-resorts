========================================================================
   ATITHI-SETU  PRINT AGENT  —  DEPLOYMENT GUIDE
   Automatic kitchen tickets (KOT) + customer bill printing
========================================================================

WHAT THIS DOES
--------------
 * When an order is placed (POS / waiter / customer QR), a Kitchen Order
   Ticket prints AUTOMATICALLY at the kitchen printer — no button needed.
 * When staff press "Print Bill" on a table, the customer invoice prints
   at the bill printer.
 * One small program (the "print agent") runs quietly on the billing PC
   and drives ALL your printers.

 The SAME program works for every restaurant. Nothing is hard-coded — it
 just needs your Restaurant ID + token, which Setup.bat asks for. Use ONE
 printer for everything, or TWO (kitchen + bill). Your choice.


WHAT YOU NEED
-------------
 1. A Windows PC at the counter that stays ON during service (the billing PC).
 2. One or two thermal receipt printers (58mm or 80mm), each INSTALLED on
    that PC so Windows can print a test page to it:
      - USB printer : plug it in, install the vendor driver, then confirm it
                      shows under  Settings > Bluetooth & devices >
                      Printers & scanners.
      - Network printer : connect to the same Wi-Fi/LAN, note its IP address.
 3. Your Atithi-Setu OWNER login.


========================================================================
 PART A — SET UP PRINTERS IN THE APP   (do this once, from any device)
========================================================================
 1. Log in to Atithi-Setu as the owner.
 2. Go to:   Restaurant  >  Kitchen Printers
 3. Click "Add a printer" and fill in:

      Name        : any label, e.g. "Kitchen" or "Counter".
      Station     : KITCHEN = food tickets for the chef
                    INVOICE = the customer bill (Print Bill button)
                    ALL     = ONE printer that prints BOTH
                              (use this if you only have one printer;
                               also tick "Default")
      Connection  : USB     = printer plugged into the billing PC (common)
                    Network = printer has its own IP address
      If USB      : "Windows printer name" = the EXACT name from
                    Printers & scanners (copy it letter-for-letter).
      If Network  : enter the printer's IP and Port (usually 9100).
      Copies      : 1  (raise it for duplicate tickets)

 4. Save. Repeat for a second printer if you have one.

      RECOMMENDED — TWO PRINTERS:
        Printer 1  ->  Name "Kitchen",  Station KITCHEN,  USB, kitchen printer name
        Printer 2  ->  Name "Counter",  Station INVOICE,  USB, bill printer name

      SIMPLE — ONE PRINTER:
        Printer 1  ->  Name "Counter",  Station ALL,  USB, your printer name,
                       tick "Default"

 5. On that page, click COPY next to "Print agent token". Keep it for Part B.
    Also note your Restaurant ID (looks like  RESTO-1234).


========================================================================
 PART B — INSTALL THE AGENT ON THE BILLING PC   (about 5 minutes)
========================================================================
 First, copy the "AtithiSetuPrintAgent" folder onto the billing PC
 (e.g.  C:\AtithiSetu\ ). If you received a .zip: right-click > Extract All.
 Everything needed is inside the folder — nothing else to download or install.

 Then pick ONE of the two install methods below.

 ----------------------------------------------------------------------
 OPTION 1 (RECOMMENDED)  —  Install as a Windows SERVICE
 ----------------------------------------------------------------------
 Best for a shop PC: starts at BOOT before anyone logs in, keeps running
 after logout, and restarts itself automatically if it ever stops.

   1. RIGHT-CLICK  Install-Service.bat  >  "Run as administrator".
      (Or just double-click it and click YES on the Windows security prompt.)
      If Windows shows "Windows protected your PC": More info > Run anyway.
   2. When asked, type:
        Server URL        : press Enter to accept https://erp.atithi-setu.com
        Restaurant ID     : e.g.  RESTO-1234
        Print agent token : paste the token from Part A
   3. It installs the "Atithi-Setu Print Agent" service and starts it.
      Done — it now runs by itself forever, including after reboots.

   Requirement: your printer must be installed in Windows for ALL users
   (the normal way — it shows in Printers & scanners for everyone). USB
   thermal printers installed with their driver already are. If a test
   print later fails with "OpenPrinter", use OPTION 2 instead.

   To remove it later:  right-click  Uninstall-Service.bat > Run as admin.

 ----------------------------------------------------------------------
 OPTION 2 (SIMPLE)  —  Start automatically at login
 ----------------------------------------------------------------------
 No admin rights needed. The agent starts when someone logs into Windows
 (fine if this PC auto-logs-in to one account during service).

   1. Double-click   Setup.bat
      If Windows shows "Windows protected your PC": More info > Run anyway.
   2. Type the same three values (Server URL / Restaurant ID / token).
   3. Done — it starts now and every time you log in, hidden in the
      background.

   To remove it later:  double-click  Uninstall.bat

 ----------------------------------------------------------------------
 Not sure which? Use OPTION 1 (Service). Use OPTION 2 only if the service
 can't see your printer, or you can't run things as administrator.


========================================================================
 PART C — TEST IT
========================================================================
 1. Place a test order in the app (any table, add an item, confirm).
        ->  a Kitchen Order Ticket should print within a few seconds.
 2. Open that table's bill and press "Print Bill".
        ->  the customer invoice should print.

 Both printed? You're live. If not, see TROUBLESHOOTING below.


========================================================================
 EVERYDAY USE
========================================================================
 * Nothing to do — the agent runs by itself.
 * Orders print kitchen tickets automatically; staff press "Print Bill"
   for invoices.
 * It restarts by itself after a reboot.
 * Keep the billing PC ON and online during service.


========================================================================
 MANAGING THE AGENT
========================================================================
 * Stop / remove it       :  Service install  ->  Uninstall-Service.bat (as admin)
                              Login install    ->  Uninstall.bat
 * Add / change printers   :  do it in the app (Restaurant > Kitchen
                              Printers). No change needed on the PC.
 * Token changed/rotated   :  re-run Install-Service.bat (or Setup.bat) and
                              paste the new token.
 * See what it is doing    :  open  agent.log  in the folder (service install).


========================================================================
 TROUBLESHOOTING
========================================================================
 Nothing prints:
   - Billing PC on and online? Did Setup.bat finish?
   - In the app, is the printer "Active", and does its Station match?
     (KITCHEN/ALL for orders; INVOICE/ALL for bills.)
   - Try a Windows test page (Printers & scanners > printer > Manage >
     Print test page). If THAT fails, it's a Windows/printer issue.

 "AUTH FAILED":
   - Wrong Restaurant ID or token. Re-copy the token from Kitchen Printers
     and run Setup.bat again.

 "OpenPrinter failed ... (err 1801)":
   - The Windows printer NAME is wrong. Copy it EXACTLY as shown in
     Printers & scanners into the printer's name field in the app.

 Kitchen ticket prints but bill doesn't (or vice-versa):
   - Check each printer's Station. Orders -> KITCHEN/ALL; bills ->
     INVOICE/ALL (or the Default printer).

 Garbled characters:
   - The printer may need a different codepage. Send us the printer model.

 Network printer won't connect:
   - Wrong IP/port, printer off, or firewall. Confirm the IP and that
     port 9100 is open.


========================================================================
 NOTES
========================================================================
 * The SAME AtithiSetuPrintAgent.exe works for ANY restaurant — only the
   Restaurant ID + token differ (Setup.bat handles that).
 * The agent only relays print tickets to your printers; it stores nothing.
 * USB printing is Windows-only. For Linux / Raspberry Pi, use network
   printers (see README.md / contact support).
